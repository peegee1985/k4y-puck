# K4Y Puck 0.4.21 / build 255 — kontrola výpadku dotyku

Datum: 23. 10. 2026.

Jde o kontrolní vydání pro ověření výpadku dotyku po zavedení hlasových oznámení. Obnovení dotyku na fyzické desce zatím není potvrzené.

- Zvuková implementace je přesně ze zdroje buildu 252. Oznámení dočasně používají původní tóny; WAV soubory a PCM dekodér se do tohoto firmwaru nepřilinkují.
- Každých pět sekund se přes USB vypisují stavy a počty dotykových paketů, platných souřadnic a stisků/uvolnění. Samostatně se počítají události grafického rozhraní. Při startu se vypíše registr verze dotykového řadiče.
- Současná rotace, písmo, správa napájení a obnova vstupů z 254 jsou zachované. Wi-Fi, párování, nastavení a SD data se nemažou.

Mezi 252 a 253 se ovladač dotyku, audio piny, I2S/DMA konfigurace ani úlohy nezměnily. Přibylo přehrávání hlasů a detail napětí baterie. Kontrola zatím neprokázala přepis paměti či konflikt pinů. Úspěšná odpověď řadiče na I2C sama nepotvrzuje funkční dotykovou vrstvu.

Po instalaci je potřeba zaznamenat USB log při klepání, podržení a tažení prstu. Teprve pak lze rozlišit chybějící dotyková data od problému jejich zpracování. Toto vydání neoznačuje displej za poškozený.

Ověření: všechny čtyři zdrojové CI prošly — ESP-IDF 5.5.2 / ESP32-S3, skutečné UI LVGL 8.3.11, firmware core a web/Convex kontrakty. Testy zahrnují 453 textových prvků, simulované doteky ve čtyřech rotacích a skutečný ovladač SPD2010 proti řadě odpovědí včetně vadných paketů a výpadku komunikace. Host test není fyzický test panelu.
